Все найденные уязвимости (особенно критические) необходимо обновлять в процессе разработки.

На текущий момент сканирования для выявления open-source уязвимых компонент проводятся для:

Исходных текстов
Бинарных файлов из дистрибутива
Системных пакетов ОС

В рамках каждого сканирования указаны места в столбце «Цепочка зависимостей», где уязвимый компонент находится, и критичность его уязвимостей.

Для каждой практики ниже таблиц с уязвимостями находится подборка версий компонентов «Версии компонент без уязвимостей», на которые рекомендуется обновляться, поскольку в них нет уязвимостей.
